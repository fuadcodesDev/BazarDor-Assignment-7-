# বাজার দর (BazarDor)

BazarDor is a responsive web application that helps users explore the prices of essential products, compare prices across markets, and track daily price changes. The application provides an easy way to see which products are becoming more expensive or more affordable.

## Live Demo

Coming soon.

## Features

- **Daily Price Tracking:** Browse essential products and view their current prices and daily price changes.
- **Rising and Falling Prices:** Quickly identify products whose prices have increased or decreased.
- **Product Categories and Sorting:** Browse products by category and sort them by price.
- **Product Details:** View product summaries, minimum, maximum, and average prices, and market-specific prices.
- **User Authentication:** Sign up and sign in using email and password, Google, or GitHub.
- **User Profile:** View account information and update your profile name.
- **Responsive Design:** Browse the application on mobile phones, tablets, and desktop computers.
